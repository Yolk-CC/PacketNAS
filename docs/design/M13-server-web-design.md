# PocketNAS Server Web 管理台改版设计规格（M13）

> 版本：M13 ｜ 范围：Server Web 管理台全站改版
> 技术约束：纯静态原生 HTML / CSS / 原生 JS，无框架、无构建步骤
> 本文档为唯一设计依据，所有数值可直接翻译成 CSS。

---

## 0. 信息架构（已定）

```
PocketNAS Web 管理台
├── overview.html   总览（新增，门面页，登录后默认落地页）
├── files.html      文件（原 index.html 文件管理器迁入）
├── library.html    图库（含子页签）
│     ├── ?tab=photos   照片（时间线，原 gallery.html）
│     ├── ?tab=people   人物（原 people.html）
│     └── ?tab=faces    识别中心（人脸模型/进度/导出导入，自设置页迁入）
├── shares.html     共享（共享路径管理，自设置页拆出，一级导航）
└── settings.html   设置（服务器名、修改密码、主题切换）
```

导航形态：
- 桌面 ≥768px：左侧固定侧边导航（宽 232px），五个一级入口，图库内用二级子页签。
- 移动 <768px：侧边导航收起，改为顶部水平滚动 tab 条（沿用现有 `.tabs` 模式的紧凑变体）。
- 登录页（login）保持独立视图，不进导航。

## 1. 设计 Token

全部 token 定义为 CSS 自定义属性，挂在 `:root`（浅色）与 `[data-theme="dark"]`（深色）。JS 只切换 `document.documentElement.dataset.theme`，组件内不写死任何颜色。

### 1.2 字号阶梯

基准 `html { font-size: 16px }`，以下用 rem：

| Token | 值 | 用途 |
|---|---|---|
| `--fs-display` | 1.75rem / 28px | 总览大数字（存储量） |
| `--fs-h1` | 1.375rem / 22px | 页面标题 |
| `--fs-h2` | 1.125rem / 18px | 卡片标题、区块标题 |
| `--fs-body` | 0.9375rem / 15px | 正文、表格、按钮 |
| `--fs-small` | 0.8125rem / 13px | 辅助说明、表头、徽标 |
| `--fs-tiny` | 0.75rem / 12px | 角标、时间戳 |

字重：400 正文 / 600 强调（标题、选中态）。不用 700 以上。
行高：正文 1.5，标题 1.3，数字统计 1.1。

### 1.3 间距阶梯（4px 基准）

`--sp-1: 4px` `--sp-2: 8px` `--sp-3: 12px` `--sp-4: 16px` `--sp-5: 20px` `--sp-6: 24px` `--sp-8: 32px` `--sp-10: 40px` `--sp-12: 48px`

- 卡片内边距：`--sp-5`（20px，移动端 `--sp-4`）
- 卡片间距：`--sp-4`（16px）
- 区块间距：`--sp-6`（24px）
- 表单控件间距：`--sp-3`（12px）

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 6px | 徽标、小标签、进度条 |
| `--radius-md` | 10px | 按钮、输入框、toast |
| `--radius-lg` | 12px | 卡片、模态框 |
| `--radius-full` | 999px | 胶囊角标、头像、环形图 |

### 1.5 阴影（低存在，暖色调）

| Token | 值（浅色） | 深色 |
|---|---|---|
| `--shadow-card` | `0 1px 3px rgba(63,58,52,.06)` | `0 1px 3px rgba(0,0,0,.3)` |
| `--shadow-raised` | `0 4px 16px rgba(63,58,52,.08)` | `0 4px 16px rgba(0,0,0,.4)` |
| `--shadow-modal` | `0 12px 40px rgba(63,58,52,.16)` | `0 12px 40px rgba(0,0,0,.5)` |

### 1.6 布局常量与断点

| Token | 值 |
|---|---|
| `--nav-w` | 232px（桌面侧边导航宽） |
| `--nav-w-collapsed` | 64px（1280px 以下可仅图标，可选） |
| `--topbar-h` | 56px（移动端顶部栏高） |
| `--content-max` | 1200px（内容最大宽） |
| `--control-h` | 40px（按钮/输入框标准高） |
| `--control-h-sm` | 32px（紧凑控件，如表格内操作） |
| `--tap-min` | 44px（移动端最小触控高） |

断点：
- `<768px`：移动布局（顶部 tab、单列、表格转卡片列表）
- `768–1023px`：平板（侧边导航、内容单列）
- `≥1024px`：桌面（侧边导航、总览双列栅格）

### 1.7 动效

- 通用过渡：`0.15s ease`（背景色、描边、阴影）
- 模态/toast 进入：`0.2s ease-out`（opacity + translateY 4px）
- 环形图/进度条数值变化：`0.4s ease-out`（`stroke-dashoffset` / `width`）
- `prefers-reduced-motion: reduce` 时全部过渡归零

### 1.8 主题切换实现

```css
:root { /* 浅色 token */ }
[data-theme="dark"] { /* 深色 token */ }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { /* 深色 token 复写 */ }
}
```

优先级：localStorage `pocket-theme`（`light`/`dark`/`auto`）> 系统偏好。设置页切换立即写入并设置 `document.documentElement.dataset.theme`，无刷新生效。`<meta name="color-scheme" content="light dark">` 让原生表单控件跟随主题。

## 2. 通用组件

所有组件为「语义化 HTML + class」模式，无 JS 依赖即可呈现默认态。

### 2.1 按钮 `.btn`

结构：`<button class="btn">文字</button>`，图标按钮内嵌内联 SVG（20×20，stroke 1.5）。

| 变体 | 样式 | 用途 |
|---|---|---|
| `.btn`（次按钮，默认） | 底 `--card`，边 `--border`，字 `--text`；悬停底 `--bg-sunken` | 常规操作 |
| `.btn.primary` | 底 `--accent`，字 `#FFF`，无边；悬停 `--accent-hover` | 每区块唯一主操作 |
| `.btn.danger` | 底透明，边 `--danger`，字 `--danger`；悬停底 `--danger-soft` | 删除、移除 |
| `.btn.ghost` | 无边无底，字 `--muted`；悬停底 `--bg-sunken`，字 `--text` | 三级操作、导航内链接 |
| `.btn.sm` | 高 32px，字 `--fs-small`，padding `0 12px` | 表格行内操作 |

状态：
- 默认/悬停：见上。
- 禁用：`disabled`，`opacity .5`，`cursor not-allowed`，无悬停效果。
- 加载：文字前加 14px 旋转圆环（CSS `border` spinner，`animation: spin 0.8s linear infinite`），宽度不变避免抖动。
- 焦点：`outline: 2px solid var(--accent); outline-offset: 2px`（全站统一，不用默认蓝色虚线）。

尺寸：高 `--control-h`（40px），padding `0 16px`，圆角 `--radius-md`，字号 `--fs-body`。移动端高度提升为 44px。

### 2.2 输入框 `.input` / 下拉 `.select` / 开关 `.switch`

- `.input`：高 40px，底 `--bg-sunken`，边 `--border`，圆角 `--radius-md`，padding `0 12px`，字号 `--fs-body`。聚焦：边 `--accent` + `box-shadow: 0 0 0 3px` 的 accent 15% 透明晕。错误态：边 `--danger`，下方红字提示 `--fs-small`。禁用：底 `--border` 50% 透明，字 `--muted`。占位字 `--muted`。
- `.select`：原生 `<select>` 同款外壳，右侧 16px chevron SVG 指示。
- `.switch`（主题开关用）：原生 `<input type="checkbox">` 样式化，轨道 44×24px 圆角 full，未选 `--border-strong`，选中 `--accent`；圆点 20px 白色，`transform: translateX` 过渡 0.15s。
- 密码输入：右侧内嵌「显示/隐藏」眼睛图标按钮（32×32，ghost）。

### 2.3 卡片 `.card`

底 `--card`，边 `--border`，圆角 `--radius-lg`，padding 20px，阴影 `--shadow-card`。
- 卡片头 `.card-head`：标题 `--fs-h2`/600 + 右侧操作区（ghost 按钮或「查看全部 →」链接）。
- 变体 `.card.interactive`（整卡可点，如图库统计卡）：悬停边 `--border-strong` + 阴影升 `--shadow-raised`，`cursor pointer`。
- 无 hover 浮起位移（避免廉价感）。

### 2.4 表格 `.table`

沿用现有 `.file-table` 并收敛：
- 表头：字 `--fs-small`/600/`--muted`，底 `--bg-sunken`，首行 sticky（`position: sticky; top: 0`）。
- 行高 48px，行间 1px `--border`；行悬停底 `--bg-sunken` 60% 透明。
- 操作列右对齐，按钮用 `.btn.sm.ghost` + 图标。
- 移动 <768px：次要列（修改时间、大小可选其一）隐藏；共享页表格转为「卡片行」（名称一行、路径一行小字、操作右下）。

### 2.5 Toast `.toast`

位置：顶部居中，`top: 16px`，`max-width: min(420px, 92vw)`。
- 结构：左侧 4px 色条 + 图标 18px + 文字；底 `--card`，边 `--border`，圆角 `--radius-md`，阴影 `--shadow-raised`。
- 类型：`.success`（绿条）/`.error`（红条）/`.info`（主色条）。
- 成功 2.5s 自动消失；错误 5s 且可点 × 关闭；同时最多 3 条，向下堆叠（gap 8px）。
- 进入动画：opacity 0→1 + translateY(-4px)→0，0.2s。

### 2.6 模态框 `.modal`

- 遮罩：`--overlay`，点遮罩默认不关闭（防误触丢失输入）；仅「取消」/×/Esc 关闭。
- 卡片：宽 `min(480px, 92vw)`，危险确认类缩窄为 400px；圆角 `--radius-lg`，阴影 `--shadow-modal`，padding 24px，`max-height: 84vh`，内部滚动。
- 结构：标题 `--fs-h2` → 正文（说明文字 `--text-secondary`）→ 底部按钮行右对齐（取消 ghost + 主操作 primary/danger）。
- 焦点管理：打开时焦点移到首个输入框或主按钮，关闭后还原；Tab 锁定在框内。
- 移动端：底部弹出 sheet 形态（贴底、圆角仅顶部 16px、宽 100%）。

### 2.7 空态 `.empty`

结构居中：64×64 线性 SVG 图标（`--border-strong` 描边色）+ 主文案 `--fs-body`/`--text-secondary` + 可选副文案 `--fs-small`/`--muted` + 可选主按钮。上下 padding `--sp-12`。各页面具体文案见 §3。

### 2.8 进度条 `.progress`

- 线性：轨道高 6px、圆角 full、底 `--bg-sunken`；填充 `--accent`（任务进行中）/`--success`（完成）/`--danger`（失败），宽度过渡 0.4s。右侧百分比 `--fs-small` `--muted`。
- 环形（总览存储图）：SVG `circle` 双环，轨道 `--bg-sunken` 12px stroke，用量 `--accent`；>85% 时转 `--warning`，>95% 转 `--danger`。中心叠大字百分比 `--fs-display` + 「已用」小字。
- 不定态（indeterminate）：填充 40% 宽，左右滑动 animation 1.2s infinite（用于等待服务端返回进度前）。

### 2.9 徽标 `.badge`

胶囊：圆角 full，padding `2px 10px`，字号 `--fs-tiny`/600。
- `.badge.accent`：底 `--accent-soft` 字 `--accent-soft-text`
- `.badge.success` / `.warning` / `.danger` / `.info`：同理配对应 soft 色
- `.badge.neutral`：底 `--bg-sunken` 字 `--muted`
- 用法：任务状态（进行中/已完成/失败）、共享状态、模型档位标签。
- 视频/LIVE 角标沿用现有 `.video-badge`/`.live-badge`（深色半透明底，不变）。

### 2.10 左侧导航项 `.nav-item`

结构：20×20 SVG 图标 + 文字，高 44px，圆角 `--radius-md`，padding `0 12px`，gap 12px。
- 默认：字 `--text-secondary`，无底。
- 悬停：底 `--bg-sunken`。
- 选中：底 `--accent-soft`，字与图标 `--accent-soft-text`，600 字重；左侧 3px 主色竖条（`box-shadow: inset 3px 0 0 var(--accent)`）。
- 图库展开时下方缩进 24px 显示三个子项（照片/人物/识别中心），子项高 36px，仅文字。
- 徽标挂载：识别中心子项可带 `.badge.warning` 显示队列数（如 `12`）。

导航整体：宽 `--nav-w`，顶部落 brand（PocketNAS 字标 `--fs-h1`/600 主色），底落「主题快捷切换 + 用户/退出」区。

### 2.11 图标规范（内联 SVG）

统一：24×24 viewBox，线性 stroke，`stroke-width: 1.5`，`stroke="currentColor"`，`fill="none"`，`stroke-linecap/linejoin: round`。继承文字色，不单独配色。

全站所需图标清单：

| 场景 | 图标 |
|---|---|
| 导航 | 仪表盘（总览）、文件夹（文件）、图片（图库）、时钟/时间线（照片子项）、人脸（人物）、芯片/扫描（识别中心）、分享节点（共享）、齿轮（设置） |
| 文件操作 | 上传（云+上箭头）、新建文件夹、下载、重命名（铅笔）、删除（垃圾桶）、排序（上下箭头） |
| 文件类型 | 文件夹、图片、视频、音频、文档、压缩包、未知文件 |
| 总览 | 硬盘/存储、照片、视频、人脸组、任务（转圈/列表）、服务器（主机）、时钟（运行时长） |
| 识别中心 | 下载（下箭头入盘）、导出（上箭头出盘）、导入、播放/开始、停止、刷新 |
| 反馈 | 成功（对勾圆）、错误（叉圆）、警告（三角叹号）、信息（i 圆）、加载（spinner） |
| 通用 | 关闭 ×、返回上级、搜索、太阳/月亮（主题）、眼睛（密码可见）、chevron 右/下 |

### 2.12 加载态

- 页面级：内容区居中 spinner（32px）+ `--muted` 文字「加载中…」。
- 区块/卡片级：骨架屏，占位块用 `--bg-sunken` 底 + 0.9s 呼吸透明度动画；统计卡用 3 条横条骨架，图库网格用正方形占位格（沿用 `--thumb-placeholder`）。
- 按钮级：见 §2.1。

### 3.1 总览 overview.html（门面页）

**页面职责**：30 秒让用户知道「NAS 健康、存了多少、在忙什么」。

桌面布局（内容区 12 列心智栅格，gap 16px）：

```
┌──────────────────────────────┬──────────────────┐
│ A. 存储卡片（占 7 列）        │ B. 服务器信息卡   │
│  左：环形图 160px             │ （占 5 列，纵向    │
│  右：用量明细 + 共享用量条    │  撑满两行高）      │
├──────────┬──────────┬────────┤                  │
│ C.照片卡  │ D.视频卡  │ E.人物卡│                  │
│ (各约1/3) │          │        │                  │
├──────────┴──────────┴────────┴──────────────────┤
│ F. 任务进度卡片（全宽）                            │
└──────────────────────────────────────────────────┘
```

- **A 存储卡**（`--shadow-raised` 强调）：左侧 160px 环形图（中心大字 `62%` + 小字「已用」）；右侧三行明细：总容量/已用/可用（数字 `--fs-h1`/600，单位 `--fs-small` `--muted`）；下方每个共享目录一条细用量条（标签 + 线性进度条 + 数值，最多 5 条，超出折叠「还有 N 个」）。

## 4. 关键交互流

### 4.1 修改密码

1. 设置页「修改密码」卡，输入当前密码 + 新密码 + 确认新密码。
2. 前端即时校验：新密码长度/复杂度（小字实时反馈）；两次输入一致性（失焦时校验，不一致红字 + 禁用主按钮）。
3. 点「确认修改」→ 按钮转加载态（防重复提交）→ `POST /api/password`。
4. 成功：toast 成功「密码已更新，下次登录请使用新密码」；清空三个输入框；按钮还原禁用。
5. 失败（当前密码错）：卡顶内嵌红条「当前密码不正确，请重新输入」，当前密码框聚焦并全选；不清空新密码。
6. 网络错误：toast error「网络异常，请稍后重试」，按钮还原可用。

### 4.2 主题切换即时生效

1. 设置页外观卡点选 跟随系统/浅色/深色（或侧边导航底部太阳/月亮图标快捷在 浅色↔深色 间切换）。
2. JS 写入 `localStorage['pocket-theme']` 并设置 `<html data-theme>`；`auto` 时移除属性交由 `prefers-color-scheme` 媒体查询接管，并监听 `matchMedia('(prefers-color-scheme: dark)')` 变化实时跟随。
3. 无刷新、无闪烁：所有颜色均走 CSS 变量；图表（存储环形图 SVG）的轨道/填充色用 `currentColor`/变量，随主题自动更新。
4. 防首屏闪烁：每个 HTML 的 `<head>` 内联一段 <10 行的启动脚本，在 CSS 加载前读取 localStorage 设置 `data-theme`。
5. 切换后 segmented 控件选中态即时更新，无需 toast（视觉本身即反馈）。

### 4.3 添加共享

1. 共享页点「添加共享」→ 模态 → 填名称 →「选择目录…」→ 目录选择器浏览 →「选择当前目录」回填路径。
2. 「添加」可用后点击 → 行内 loading → 成功 toast「已添加共享『照片』」并插入表格行；失败 toast error 并保留模态输入。
3. 若这是首个共享，legacy 警告条淡出消失。

### 4.4 下载模型并开始识别

1. 识别中心选档位 →「下载模型与运行库」→ 进度条实时更新（1s 轮询）→ 完成 toast +「已下载」徽标。
2. 「应用」切换档位 → toast 确认。
3. 「开始识别」→ 状态徽标转「进行中」，进度 1s 轮询，识别中心子页签徽标同步显示剩余数；离开页面后台继续，回总览页亦可见同一任务进度行。

## 6. 工程落地要点

1. **迁移路径**：新增 `overview.html`、`shares.html`、`library.html`；`index.html` 内容迁入 `files.html`；旧 `gallery.html`/`people.html` 逻辑并入 library 子页；`settings.html` 删除共享与人脸卡片。旧 URL 建议 301 或保留跳转正页，避免客户端书签失效。
2. **样式表结构**：单文件 `style.css` 分区（token → base → 组件 → 页面 → 深色覆写），沿用现有分区注释风格；新增 `theme.js`（约 30 行，主题读写 + 导航主题按钮）被所有页面引用。
3. **共用壳**：侧边导航/页头为静态 HTML 片段，各页面复制粘贴（无框架下接受重复），由 `theme.js` 统一处理选中态（按 `location.pathname`）与主题按钮。
4. **新增接口需求**（设计侧依赖，需后端确认）：`GET /api/overview`（存储/统计/服务器信息聚合）、`GET /api/tasks`（任务列表与进度）、共享的增删改分项接口（替代整页保存）。
5. **可访问性**：所有图标按钮带 `aria-label`；导航选中项 `aria-current="page"`；模态 `role="dialog"` + 焦点锁定；色彩对比度正文 ≥4.5:1（已按 token 校验：浅色 `#3F3A34` on `#FAF8F5` ≈ 10.6:1，主色按钮白字 on `#B26F3F` ≈ 4.6:1）。
6. **触控**：移动端所有可点目标 ≥44px（按钮、tab、表格行操作已按此设计）。
