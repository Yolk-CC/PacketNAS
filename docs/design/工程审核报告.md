# PocketNAS 工程审核报告

基线：master @ v0.13.0（2026-08-22）。审核方式：三个并行只读审核（Go 服务端 / Android 两端 / 架构与工程规范），本文档为汇总。

## 总体结论

代码质量**中上**：服务端分层清晰（handler → service → store，无循环依赖），路径穿越防护扎实，SQL 全参数化，认证中间件覆盖完整；客户端协程生命周期使用规范，ListAdapter/DiffUtil、设计令牌落实良好；三端 API 契约经逐一比对**零漂移**；无 GPL 许可证污染。

主要风险集中在三处：**两个 P0 正确性缺陷**、**资源生命周期细节**（ExoPlayer/OkHttpClient/缩略图缓存）、**工程基础设施落后于代码质量**（仓库膨胀、无日常 CI、版本号漂移）。

### 工程基建
13. `dist/` 三个约 11MB 二进制提交进 git（当前+历史），CI 已传同名 assets 纯属冗余；需 filter-repo 清历史
14. 22 个已合并分支（m6..m14、backend-m1..5、web-m1..4 等）未清理
15. 根 .gitignore 仅两行，不覆盖 dist/、*.aar、.gradle/、.pocketnas/
16. 无 push/PR 门禁 CI，回归只能发版时发现；M11 真实模型 smoke 是 continue-on-error，ONNX 绑定坏了不挡发版
17. 版本号五处漂移：server APK 0.5.0 / client 0.10.0 / 二进制 ldflags / 代码默认 dev，versionCode 恒 1，与 tag 不联动

## P2 — 改进项（摘要）

**服务端**：tokenStore 无主动清理+登录无限速；http.Server 无超时（Slowloris）；Shutdown 不调各模块 Close（Android 反复起停泄漏 goroutine/fd）；转码失败任务不可重试、queued 卡死；writeError/EvictLRU/escapePath 等五处重复代码；".pocketnas" 目录名硬编码三处；discovery serverName 未过滤 `|`；ProcessedMap 用字符串存 mtime。
**Android**：disconnect 不可持久（重启自动重连）、token 明文 SharedPreferences；ViewerData 全局 object 传参进程重建后白屏；自绘组件（FastScroller/吸顶日期头）硬编码颜色与裸像素尺寸绕开设计令牌；ViewModel 硬编码中文错误串；多选 notifyDataSetChanged 全量刷新；切服后任务栈叠多层 MainActivity；冗余权限（CHANGE_WIFI_MULTICAST_STATE / WAKE_LOCK）；server APK 用系统内置 drawable 当图标；WebView 未限制导航域；Go core 启动失败 UI 无限"启动中"。
**架构**：`POST /api/files/move` 是死契约（无前端调用方）；`/api/gallery/scan` 命名误导（实为只读状态）；faces schema 无版本号，旧库迁移全靠手动导出导入；无 OpenAPI，契约靠纪律维持；仓库无 LICENSE / 第三方 NOTICE（APK 重分发 onnxruntime MIT 需保留版权声明）；goexif 停在 2019 归档版。
